# Input Code Generator

Расширение VS Code создаёт C++ программу ввода по схеме. Команда: **Input Generator: Generate C++ Input**.

## Использование

1. Открой палитру команд через Cmd+Shift+P на Mac или Ctrl+Shift+P на Windows/Linux.
2. Вызови команду генератора.
3. Введи `n int; a int[n]; x double`.
4. Получи новую несохранённую вкладку C++ с заголовками, main, объявлениями и чтением.
5. Сохрани результат как .cpp и допиши алгоритм задачи.

## Формат схемы

Записи разделяются `;`. Обычная переменная: `имя тип`. Массив: `имя тип[размер]`. Типы: int, double, string. Размер — имя ранее объявленной обычной переменной int. Между именем и типом требуется один или несколько обычных пробелов. Пробелы вокруг записей и одна завершающая точка с запятой допустимы. Внутри int[n] пробелы не используются. Старый формат с двоеточием не поддерживается.

Пример `n int; a int[n]` создаёт чтение n и вектора a из n чисел. Подходящие данные C++: первая строка `5`, затем `1 2 3 45 5`. Перенос строки равнозначен пробелу при чтении через >>.

При любой ошибке показывается «Ошибка ввода». Escape отменяет команду; пустая подтверждённая схема считается ошибкой.

## Ограничения

Программа предполагает корректные входные данные и неотрицательные размеры. Строки читаются до пробела. Поддерживается один уровень массива. Расширение генерирует код ввода; алгоритм задачи и компиляцию C++ пользователь выполняет отдельно.

## Разработка

Открой эту папку, установи зависимости через `npm install`, выполни `npm run compile` и нажми F5. В окне Extension Development Host вызови команду генератора.

Сборка: проверка типов → ESLint → esbuild → dist/extension.js. Модули: model.ts, names.ts, parser.ts, generator.ts, extension.ts. Подробные учебные материалы находятся в папке user-version рядом с папкой упражнения.

## Тесты и совместимость

Тест в src/test пока является примером Yeoman с indexOf. Для функциональной проверки выполни npm run test:logic и случаи из туториала. Заявленный минимум редактора в package.json нужно согласовать с версией @types/vscode перед упаковкой; подробности приведены в туториале.
